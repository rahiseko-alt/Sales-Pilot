# Sales Pilot

見込み客の発見、企業調査、改善提案、個別メール、返信対応、案件管理を継続する営業担当AIです。商談・契約・重要判断は人間へ引き継ぎます。

## 起動

```powershell
cd sales-agent
python server.py
```

ブラウザーで http://127.0.0.1:8765 を開きます。Python標準ライブラリを使用します。

Claude CodeのサブスクログインとAgentMailを接続できます。設定は [営業AIのREADME](sales-agent/README.md)、業務範囲は [仕様](sales-agent/SALES-SPEC.md) を参照してください。

## メール品質

- 冒頭一文で用件を伝え、改善概要・出典付き参考数字・小さな依頼一つに絞ります。
- 企業規模と対象工程の業務量に合わせ、規模不明なら一工程の小さな改善を提案します。
- 作成時と送信前に品質方針を読み、Claudeが根拠・会話履歴を審査します。問題があれば一度修正し、解消できなければ送信を保留します。
- 配信停止、重複送信の防止、送信先制限、品質履歴の増分監査を実装しています。
